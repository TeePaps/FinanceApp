Restart the Flask dev server by running the cross-platform launcher from the project root: `python3 restart_server.py restart` on macOS/Linux, `py restart_server.py restart` (or `python`) on Windows. The script finds the venv itself, kills any existing server, starts a detached one, and health-checks http://127.0.0.1:8080/healthz (exit code 0 = healthy). Report the outcome to the user; if it exits non-zero, show the log tail it printed (from logs/server.log).
